# 30日間の試読・改善計画

2026年10月9日〜11月7日（30日間）  
入口：[退職したら、最初に何をする？](https://gerrygao1995-coder.github.io/japan-life-playbook/start/leaving-work.html)

今回の範囲は、第1段階の特集制作・公開・スマートフォン相当の自動操作による確認と、試読・告知資料の準備です。日本で暮らす読者による試読は未実施です。後日の募集や投稿は制作者が実行するか、その時点で別途依頼します。自動実行や予約投稿は設定していません。

## 確かめたいこと

退職前後の困りごとから入った読者が、「次にすること」と「公式の確認先」を見つけられるかを確かめます。まずは一つの場面で使いやすさを改善します。

最初の目標は**実読者20人・有効な改善意見5件**です。日本で暮らす日本語読者に実際に読んでもらうための実験目標で、流量や拡散の予測ではありません。案内数と実読者数は分けて記録します。

独立した第三者の専門家は、この実験では未招待・未確認です。一般読者の試読や自動操作の確認を、制度内容の専門監修として数えません。

## 最初の20人へ届ける方法

候補は、制作者の知人、生活情報に関心のある人、紹介を受け付けるコミュニティです。まず少人数に案内し、伝わりにくさを直してから次へ進みます。コミュニティではその場の紹介ルールに従います。

スマートフォンとパソコン、制度の説明を読むのに慣れた人と不慣れな人の両方を、無理のない範囲で含めます。実際の退職予定や家計は尋ねず、架空の場面で試せます。同じ知人集団に偏った場合は、振り返りに残します。

[募集文](CAMPAIGN.md)と[5分の試読台本](READER-FEEDBACK.md)を使い、原文の個人情報を取り除いて課題を記録します。読者の言葉を公開するときは、本人の了承を得ます。

## 指標の数え方

| 指標 | 定義 | 初期状態 |
| --- | --- | --- |
| 案内数 | 実際に個別案内した人数。公開投稿の表示数は別 | 未実施 |
| 実読者数 | 少なくとも一つの記事を読んだと本人が回答した人数。同じ人は1人 | 未計測 |
| 回答者数 | 5問のうち1問以上に回答した人数。途中終了も記録 | 未計測 |
| 有効な改善意見 | URL・見出しなどの位置と、具体的な迷い、操作の問題、根拠付きの訂正があるもの | 未計測 |
| 原資料への到達 | 質問2で、原資料を見つけて開けたと答えた人数。自己申告として集計 | 未計測 |
| 修正後の変化 | 同じ課題の再試読で、解消した点と残った点 | 未実施 |

「よかった」だけの感想は改善意見5件には数えません。同じ問題が3人から出たら意見1件・報告3人とします。1人から異なる問題が複数出た場合は別件にできますが、人数は増やしません。

閲覧数やクリック率を計測していなければ「不明」とします。自己申告の実読数をアクセス解析の訪問者数に置き換えず、少人数の結果を日本の読者全体へ一般化しません。

## 改善の順番

1. 対象・期限・申請先の誤解、根拠と本文の食い違いを確認する。
2. リンク切れ、文字や操作の支障を直す。
3. 用語、読む順番、見出しや共有文を改善する。

専門家へ確認を依頼する場合は記事と論点を絞り、確認範囲と日付を本人の了承のもとで記録します。依頼中の段階で「監修済み」と表示しません。

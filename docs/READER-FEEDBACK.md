# 5分の試読とフィードバック

2026年10月9日作成。**募集・試読は未実施です。**  
対象：[退職したら、最初に何をする？](https://gerrygao1995-coder.github.io/japan-life-playbook/start/leaving-work.html)

確かめるのは、次の行動と確認先が伝わるかです。参加者本人への制度適用や受給可否の判定は行いません。

## 最初の30秒

> 5分ほど、生活ガイドの分かりやすさを試していただけませんか。「退職する予定で、次の仕事はまだ決まっていない人」という架空の場面で読んでください。退職経験は不要です。答えにくい質問は飛ばせますし、途中で終えても構いません。実名、勤務先、住所、給与、健康状態などの個人情報は書かないでください。

制作者は操作を先回りして説明せず、迷った箇所を確認します。

## 5つの質問

| 目安 | 読者への質問 | 確認すること |
| --- | --- | --- |
| 0:30〜1:30 | **1. 最初に読む項目を一つ選んでください。読んだ後、次に何をすればよいと思いましたか。** | 項目を選べるか、具体的な一歩が伝わるか |
| 1:30〜2:30 | **2. 選んだ項目の原資料へのリンクを探し、開いてください。見つかりましたか。ページは開けましたか。** | 参照先へ到達できるか |
| 2:30〜3:20 | **3. 注意点を読み、自分で確認が必要だと思ったことを一つ教えてください。見つからなければ、そのまま教えてください。** | 対象や条件の違いが伝わるか |
| 3:20〜4:10 | **4. 迷った箇所や分かりづらい言葉はどこでしたか。URLか見出しと、どう直ると助かるかを教えてください。なければ「なし」で構いません。** | 位置と理由のある改善点 |
| 4:10〜5:00 | **5. どんな場面なら、このガイドを人に紹介できそうですか。紹介しにくいなら、その理由を教えてください。** | 伝わった価値と、紹介をためらう理由 |

5分で一度終了します。原資料の全文読解や実際の投稿・共有は課題に含めません。

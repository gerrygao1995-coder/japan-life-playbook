## 引っ越し先で医療と救急の連絡先をそろえる

体調を崩す前に、普段の受診先と緊急時の相談先を確認する順番です。

1. 医療情報ネットで通える医療機関を調べる。
2. かかりつけ医の候補に受診方法を確認する。
3. 地域の救急相談番号と受付時間を保存する。
4. 薬の情報をまとめ、急変時は119に伝える内容を確認する。

## 疲れが続く一週間を立て直す

小さな休息から始め、困りごとが続くときは相談へ進みます。

1. 体調を見て負担の少ない休み方を選ぶ。
2. 睡眠と休養感を振り返る。
3. 悩みを短く書き、話したいことを整理する。
4. 生活への支障が続くなら相談窓口や医療機関へつなぐ。

1. ハザードマップで必要な避難を確認する。

3. 食料と携帯トイレの不足分を確認する。
4. 家族等で避難を始める情報と行き先を共有する。

## 健診の案内が届いたら、受けた後まで予定に入れる

受診できる健診を確かめ、結果の確認と必要な受診につなげる順番です。

1. 加入している保険や勤務先の案内から、受診先と費用を確認する。
2. 予約を取り、受診後に結果を見る日も予定に入れる。
3. 要精密検査や要治療の指示があれば医療機関に連絡する。
4. 保健指導の対象なら利用方法を確認し、診察には経過をまとめて持参する。

## 夏本番の前に、冷房と外出の備えをする

体調と住まいを確認し、厳しい暑さの日に予定を変えられるようにします。

1. 冷房を点検し、無理のない日常活動を続ける。
2. 室温を確認する方法と、暑い日の外出を見直す基準を決める。
3. 冷房が使えないときに過ごせる施設と移動方法を調べる。
4. 熱中症が疑われる場合の冷却と救急要請を家族などと確認する。

## 退職した・退職を考えている

期限が短い保険の切替えと、収入を支える手続きを先に整理する。

1. 退職前に健康保険の選択肢と申請期限を確認する。
2. 離職票を確認し、働ける状況ならハローワークへ。療養等で働けない場合は受給期間延長を相談する。
3. 年金・国民健康保険の負担軽減を確認し、必要な書類を保存する。
4. 生活が落ち着いたら税の還付と再就職の学びを検討する。

4. 生活費や住まいに差し迫った不足がある場合は、家計整理を待たず公的窓口へ相談する。

安全と健康を先に確保し、社内相談と外部の解決支援を選ぶ。

1. 差し迫る危険や強い体調不良には、記録作りより安全確保と受診等を優先する。
2. 出来事と希望する配慮を整理し、相談先と共有範囲を確認する。
3. 相談後の不利益も記録し、労働局など外部窓口へ相談する。
4. 話合いで進まない場合は、あっせんや労働審判等の条件と費用を確認する。

## 引越しが決まった

契約の確認から住所変更まで、先に日程を押さえる順番。

1. 契約の種類・総額・解約条件を確認する。
2. 運送・不用品回収・ライフラインの予定をそろえる。
3. 役所と郵便の届出を準備し、入居時の状態を記録する。

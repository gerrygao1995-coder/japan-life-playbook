# 23 契約・消費者被害

契約前の確認と、トラブル時の早い相談を習慣にする。

<a id="consumer-01"></a>

### 契約で困ったら188か地域の消費生活センターへ

強引な勧誘、解約できない契約、商品トラブルなどは消費生活相談へ。相手とのやり取りを残して、早めに相談する。

- **対象の目安：** 消費者トラブルに遭った人
- **費用の目安：** 条件による
- **取りかかる時間の目安：** 15分
- **根拠の種類：** 公的制度
- **内容確認日：** 2026-10-09

**この一歩で、変えられること**

契約に合う対応方法と相談先が分かる。

**やること、順番に**

1. 契約書、広告、決済記録、メッセージを保存する。
2. 消費者ホットライン188、または地域のセンターへ連絡する。
3. 契約日と困っていること、希望する解決を具体的に伝える。

**先に確かめたいこと**

- 相談は無料だが188には通話料がかかる。受付時間は窓口によって異なり、返金が保証されるわけではない。

**根拠・公式の確認先**

- 消費者庁：[消費者ホットライン](https://www.caa.go.jp/policies/policy/local_cooperation/local_consumer_administration/hotline/)

*記事ID：consumer-01*

### クーリング・オフは取引の種類と期限をすぐ確認する

訪問販売などで契約を取り消したいときは、制度の対象か確認する。書面や電子的方法で通知し、送った証拠を保存する。

- **対象の目安：** 勧誘を受けて契約した人
- **費用の目安：** 条件による
- **取りかかる時間の目安：** 15分
- **根拠の種類：** 公的制度
- **内容確認日：** 2026-10-09

**この一歩で、変えられること**

使える取消しの機会を期限前に検討できる。

**やること、順番に**

1. 契約した方法、契約日、受け取った書類を整理する。
2. 国民生活センターの案内で対象取引と期間を確認する。
3. 通知の控えと送信・発送の記録を保存し、不明点は消費生活センターへ相談する。

**先に確かめたいこと**

- 通信販売に一般的なクーリング・オフ制度はない。取引の種類や条件で扱いが異なる。

**根拠・公式の確認先**

- 国民生活センター：[クーリング・オフ](https://www.kokusen.go.jp/soudan_now/data/coolingoff.html)

### ネット注文の最終確認画面を保存する

広告の初回価格だけで決めず、注文確定前に総額・回数・解約条件を確認する。画面を保存しておくと相談時にも役立つ。

- **対象の目安：** ネット通販を使う人
- **費用の目安：** 無料
- **取りかかる時間の目安：** 5分
- **根拠の種類：** 公的推奨
- **内容確認日：** 2026-10-09

**この一歩で、変えられること**

意図しない定期購入や条件の認識違いを防ぎやすい。

**やること、順番に**

1. 最終確認画面で数量、定期購入の有無、支払総額を読む。
2. 解約方法、期限、返品条件まで確認する。
3. 画面と注文確認メールを保存してから購入する。

**先に確かめたいこと**

- 保存した画面があっても自動で返金されるわけではない。不審な表示や取消しの可否は消費生活センターへ相談する。

**根拠・公式の確認先**

- 消費者庁：[ネット通販の最終確認画面を保存しましょう](https://www.caa.go.jp/policies/policy/consumer_transaction/amendment/2021/notice04/index.html)

*記事ID：consumer-03*

### サブスクは解約完了まで確認する

使わなくなったアプリを削除するだけでは、サブスクリプション契約は終了しない。契約した窓口から解約する。

- **対象の目安：** サブスクを利用する人
- **費用の目安：** 条件による
- **取りかかる時間の目安：** 15分
- **根拠の種類：** 公的推奨
- **内容確認日：** 2026-10-09

**この一歩で、変えられること**

不要な契約の自動更新を防ぎ、解約後も残る請求を確認できる。

**やること、順番に**

1. カード・口座明細から定期的な支払いを洗い出す。
2. サービスやアプリストアなど、契約した窓口で解約方法を確認する。
3. 解約完了画面を保存し、次回請求がどうなるか確認する。

**先に確かめたいこと**

- 無料体験でも期間終了後に有料になる場合がある。日割り返金や解約後の利用期間は契約による。

**根拠・公式の確認先**

- 国民生活センター：[サブスクリプション アプリの削除だけでは解約になりません](https://www.kokusen.go.jp/mimamori/mj_mailmag/mj-shinsen545.html)

<a id="consumer-05"></a>

### 緊急修理でも作業前に料金の内訳を確認する

水漏れなどで急いでいるときほど、広告の「○円から」だけで依頼しない。出張料や見積料も含め、開始前に確認する。

- **対象の目安：** 住まいの修理を頼む人
- **費用の目安：** 条件による
- **取りかかる時間の目安：** 15分
- **根拠の種類：** 公的推奨
- **内容確認日：** 2026-10-09

**この一歩で、変えられること**

想定外の高額請求や作業内容の食い違いを減らせる。

**やること、順番に**

1. 依頼前に出張料、見積料、キャンセル料の有無を聞く。
2. 作業内容と費用の内訳を書面等で確認し、追加作業の条件も聞く。
3. 納得できなければ契約を急がず、困ったときは消費生活センターへ相談する。

**先に確かめたいこと**

- 緊急性によって比較できる範囲は異なる。クーリング・オフの可否は勧誘・依頼の経緯で変わるため個別確認が必要。

**根拠・公式の確認先**

- 国民生活センター：[水道に関する訪問販売や修理のトラブル](https://www.kokusen.go.jp/t_box/data/t_box-faq_qa2012_52.html)

*記事ID：consumer-05*

### 海外通販のトラブルは越境消費者センターを使う

日本から海外事業者と買い物をして、返品・配送・請求で困ったときはCCJに相談できる。言葉や商習慣の違いを一人で抱え込まない。

- **対象の目安：** 海外通販を使う人
- **費用の目安：** 無料
- **取りかかる時間の目安：** 30分
- **根拠の種類：** 公的制度
- **内容確認日：** 2026-10-09

**この一歩で、変えられること**

海外取引に対応する相談先へ状況を伝えられる。

**やること、順番に**

1. 販売事業者の所在国と連絡先を確認する。
2. 注文、支払い、配送、問い合わせ履歴を整理する。
3. CCJの対象と相談方法を確認し、フォーム等から状況を伝える。

**先に確かめたいこと**

- 対応できる範囲は相手国・事業者・取引内容で異なる。解決や返金を保証する窓口ではない。

**根拠・公式の確認先**

- 国民生活センター：[越境消費者センター（CCJ）](https://www.ccj.kokusen.go.jp/)

*記事ID：consumer-06*

- **対象の目安：** 訪問買い取りを利用する人
- **費用の目安：** 無料

3. 売却するなら品名と金額の書面を受け取る

**先に確かめたいこと**

- 訪問購入の規制には対象外の物品や取引があります。困ったら早急に消費生活センターへ相談します。

**根拠・公式の確認先**

### 注文していない荷物は契約の有無を確認する

家族の注文や贈り物、誤配と、代金目的の送り付けを区別します。

- **対象の目安：** 身に覚えのない荷物が届いた人
- **費用の目安：** 無料
- **取りかかる時間の目安：** 15分
- **根拠の種類：** 公的推奨
- **内容確認日：** 2026-10-09

**この一歩で、変えられること**

不要な代金の支払いと誤処分を避けやすくなる。

**やること、順番に**

1. 宛名と家族の注文履歴を確認する
2. 不明な請求にはすぐ支払わない
3. 送り付けか判断できなければ188へ相談する

**先に確かめたいこと**

- 金銭目的で一方的に送られた商品は直ちに処分できる場合がありますが、誤配や贈り物は別です。

**根拠・公式の確認先**

- 消費者庁：[身に覚えのない自分宛ての商品が届いたあなた](https://www.caa.go.jp/policies/policy/consumer_transaction/amendment/2021/notice/index.html)

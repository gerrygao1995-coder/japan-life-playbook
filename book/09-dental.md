# 09 歯と口

みがき方から食べにくさの相談まで、口の手入れを続ける。

<a id="dental-01"></a>

### 磨き残しやすい場所を歯科で教わる

歯ブラシの大きさや動かし方を、自分の歯並びと磨き方に合わせる。

- **対象の目安：** すべての人
- **費用の目安：** 費用あり
- **取りかかる時間の目安：** 継続
- **根拠の種類：** 公的推奨
- **内容確認日：** 2026-10-09

**この一歩で、変えられること**

歯ブラシの大きさや動かし方を、自分の歯並びと磨き方に合わせる。

**やること、順番に**

1. 今使っている歯ブラシと磨きにくい場所を伝える
2. 歯科衛生士に毛先の当て方を見てもらう
3. 教わった順序で歯の表・裏・かみ合わせを磨く

**先に確かめたいこと**

- 強くこするほどよいわけではない。痛みや出血が続く場合は歯科へ相談する。

**根拠・公式の確認先**

- 厚生労働省：[歯ブラシ・歯磨剤の選び方と使い方](https://iiha.mhlw.go.jp/column20241129.html)

**やること、順番に**

### 甘い飲み物をだらだら飲む習慣を見直す

飲食の回数と時間を意識して、歯が糖に触れる機会を減らす。

- **対象の目安：** すべての人
- **費用の目安：** 条件による
- **取りかかる時間の目安：** 継続
- **根拠の種類：** 公的推奨
- **内容確認日：** 2026-10-09

**この一歩で、変えられること**

飲食の回数と時間を意識して、歯が糖に触れる機会を減らす。

**やること、順番に**

1. 机やバッグに常備している飲み物を確かめる
2. 普段の水分補給用に水や無糖のお茶を用意する
3. 甘い物は時間を決めて楽しむ

**先に確かめたいこと**

- 低血糖への対応など医療上必要な糖分補給は別に考える。乳幼児の栄養は専門職と相談する。

**根拠・公式の確認先**

- 厚生労働省：[ライフステージ別にみたむし歯の特徴](https://kennet.mhlw.go.jp/information/information/teeth/h-02-003.html)
